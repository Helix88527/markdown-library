# 文件位置 命名与恢复

默认源文件所在目录为项目位置；文章提取器默认使用 <stem>_处理结果，用户指定的独立项目输出可按规划使用。原始材料始终保留。

永久成果：
- 原始媒体、原 HTML 及资源、外部逐字稿原件。
- 01_原始逐字稿的四格式与 manifest，或 01_原始正文.md 和 00_资料信息.json。
- 媒体当前人工优先的 02_校正逐字稿.md；普通文字可选 02_整理正文.md，旧 02_校订正文.md 仍可用。
- <标题>.md、其实际图片、参考资料目录和原件／访问记录。
- 需要时的 03_视觉资料.docx、视觉 manifest 与最终 assets。

自动工作目录包括 00_阶段交接、01_转写分段、03_视觉资料工作区；文章原图候选为 03_图片候选。最终已引用图片是永久依赖，不能随候选清理删除。人工笔记与补充资料不要放入自动清理目录。

成稿默认平铺 <标题>.md，附件留在原始资料或原项目并重定位链接，不创建标题目录或附件副本。同名不同内容不覆盖；比较后用新文件名保留修订。旧目录归档不批量迁移。

状态优先于文件名猜测；检查内容与哈希，不只看存在。partial/tmp 不是完成成果。已完成段须满足来源一致、状态 complete、输出及哈希有效，才能复用。当前 02、人工视觉复核和当前成稿优先于机器旧稿。

未开始或未完成第二阶段、用户暂停、来源变化、归档失败、未知文件或锁存在时保留交接。媒体清理由阶段管理器对白名单普通文件执行，最后清理状态凭据；不递归强删、不删除未知文件、不跟随符号链接或 junction。
