# 内容整理与说法核验

四层分开：原材料内容、必要的整理或识别修正、外部背景、整理者分析与核验。外部证据不能改写“原作者说过什么”。

现成文字以内容组织、说法核验和背景为主。一般保留措辞，适当整理标题、段落、列表，检查提取边界和明显缺漏。不要把正常文字默认当成识别错误稿，不为普通排版制造校正表。发现乱码、OCR／提取错误或用户要求校对时才修正并说明。

媒体逐字稿继续校正有依据的识别错误，逐段保留有效主张、推理、故事、不同例子、数字、限定条件、预测、反例与问答。只去掉无信息填充、机械重复和页面噪声；未知专名不凭印象补造。现成文字也要保留这些有效内容，但不必套用媒体审校程序。

原作者的事实错误保留归因，再在核验层说明。转载原文、附言、引用与回复分开；传播行为不证明完全认同。主题分析解释论点、论据、推理和条件，背景只补理解所需内容，不另写重复全文。

重要、争议、时效性强的说法按证据缺口核验。优先原始资料和可靠公开来源，实际打开并保存采用内容，引用紧邻支持的结论；区分发表时语境与当前状态。

| 结论 | 含义 |
|---|---|
| 有支持 | 证据支持所述具体范围 |
| 部分支持 | 仅部分、条件或范围获得支持 |
| 证据冲突 | 存在实质相反证据，需并列说明 |
| 无法核实 | 证据缺口仍存在，不等于证伪 |
| 不适用 | 价值判断、尚未到期预测等不宜硬判真假 |

1—5 分仅为可选、有理由的辅助判断，不是概率。报道不等于已证实，相关不等于因果；整理者推断注明。核验条目按内容需要，不凑数，也不把工作重点移到证明原文文字无误。
