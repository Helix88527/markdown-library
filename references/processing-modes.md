# 媒体时长和处理模式

90 分钟仅适用于完整转写／完整听校；01:30:00.000 是短媒体，01:30:00.001 是长媒体。它不是 token 上限或完成时长承诺。

| 路线 | 行为 |
|---|---|
| 文章、推特、纯文字整理 | 连续处理，尊重用户停止点 |
| 逐字稿复用、选择回听 | 按选定范围，不套用 90 分钟 |
| 完整媒体不超过 90 分钟 | 默认 continuous，不再询问短媒体阶段偏好 |
| 完整媒体超过 90 分钟 | 展示分段范围，用户未选择模式才询问 |
| 已有明确连续授权 | 说明技术计划后沿用，不重复问 |
| 旧任务 | 按现有状态，不跨越用户暂停点 |

长媒体给出均衡段数与全部范围，询问保留检查点连续完成，或每段等待确认。默认 ceil(分钟数/60)，长媒体至少两段；切点两侧各 10 秒重叠，使用全局时间。自然停顿调整在确认前完成，确认后不静默改范围。

continuous 使用 run-continuous，一个进程逐段落盘并复用模型，失败保留已完成段，第一阶段结束后直接第二阶段。staged 每次继续仅开放下一段，最后一段完成后仍需确认第二阶段。用户说停时保留状态。

init 默认 continuous；短媒体可不带 --confirmed-by-user。长媒体或 staged 必须携带该标志，依据是本次选择或已有明确连续授权。视频画面选择独立，转写授权不自动等于画面分析授权。
