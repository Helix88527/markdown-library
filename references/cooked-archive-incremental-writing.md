# 回查成稿与本期增量

校正和最终分析时，使用 search_cooked_archive.py 对当前 01／02 检索成稿。每次读取当前成稿文件并记录修改时间、SHA256 和大小，不用源项目副本或旧缓存代替。排序只是候选，须实际阅读命中段落。

平铺 Markdown 与旧 bundle-1 项目归档均可检索；旧目录归档仅把 manifest 指定的入口当作成稿，参考 Markdown 不混入往期成稿。用户编辑当前入口后，检索仍读取其当前内容，不用归档旧哈希压过人工修订。

压缩机械重复、增加信息，不删本期有效内容。旧稿已有的观点仍保留本期必要语境，使新稿独立可读；可补入前情、本期新增、变化和冲突。旧稿是二次线索，关键事实追溯原来源，时效性或争议事项重新核验。不能因为往期写过而省略本期有效内容；媒体仍保留完整校正全文，普通文字不额外引入逐字审校。
