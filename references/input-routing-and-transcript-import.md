# 材料角色与逐字稿导入

先用 inspect_project.py 区分主材料、参考资料、已有成果，再对媒体用阶段管理器 inspect。参考目录不参与主材料批处理；用户指定文件优先，文件格式不决定其角色。

同一项目有多种合理主路线而用户未选时，一次说明可用文件及质量、成本差异：复用逐字稿并按需回听（推荐），只整理逐字稿，重新完整转写并对照，分别处理或自定组合。不得因成本最低擅自改变用户目标。已选择来源、深度或组合不再询问；程序生成的派生音频不是新材料选择。

```text
<Python> scripts/media_stage_manager.py --database-root <根目录> import-transcript <明确稿件> --task-dir <项目> --source-software <软件名> --confirmed-by-user --json
```

支持 TXT、MD、SRT、VTT 及脚本已支持的结构化格式。保留原件和哈希，记录来源软件、缺陷和是否音频核验。没有时间戳不得编造。规范化不覆盖原件，人工稿优先。仅纯文字整理不套用媒体时长阈值；完整听校才应用 90 分钟。

用户只要求整理现成文字时，重点是内容、说法核验与背景，不默认逐字校订；识别校正或听校才按所选范围比对原文或音频。文件头区分文字整理、选择性回听和完整听校。多版本不得强行拼成同一稿。视频画面范围独立于此决定。
